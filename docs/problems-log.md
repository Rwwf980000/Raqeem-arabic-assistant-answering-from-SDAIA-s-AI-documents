### 2. هل استخدام ملفات سدايا قانوني؟ (2026-10-12) ✅
- **المشكلة:** الملفات منشورة للعموم، لكن هذا لا يجعلها "مفتوحة المصدر".
- **السبب:** شروط استخدام موقع سدايا تمنع النسخ أو التوزيع أو الأعمال المشتقة "لأغراض عامة أو تجارية" بدون موافقة مكتوبة.
- **الحل (قاعدة للمشروع):** الاستخدام الخاص للتعلم مسموح. لا تُرفع ملفات PDF ولا قاعدة Chroma إلى repo عام. ذكر عنوان الوثيقة ورابطها مسموح. أي نشر للعموم يحتاج موافقة من Info@sdaia.gov.sa.

### 3. الحروف العربية بأشكال العرض (2026-10-12) ✅

### 4. التطويل والحروف المكررة (2026-10-12) ✅
- **المشكلة:** كلمات مثل `مــبــــــادئ` في ملفات كثيرة، و`المؤشررررر` و`مسررررتوى` في NAII العربي.

### 5. الأرقام والأقواس بترتيب خاطئ (2026-10-12) 🟡
- **المشكلة:** مثل `)292` بدل `(292)`، و`ه وهي الجهة29/12/1440 ) وتاريخ471/`.
- **السبب:** خلط اتجاه الكتابة (يمين ويسار) عند الاستخراج.
- **الحل:** تُرك كما هو لأنه شكلي ولا يؤثر كثيراً على البحث.

### 6. الجداول والصور (2026-10-12) 🔴
- **المشكلة:** pypdf يقرأ النص فقط. الصور (مثل رسومات محاور NAII) تضيع، والجداول تتحول لكلمات متتالية بلا صفوف وأعمدة، وقد يقطعها التقطيع نصفين.
- **أفكار الحل:** `pdfplumber` و`extract_tables()` ثم تحويل الجدول إلى Markdown كمقطع واحد، أو `pymupdf4llm` مع `MarkdownHeaderTextSplitter`، أو نموذج رؤية (llava / qwen2.5vl) يصف الصور.

### 7. `clean()` يحذف الأسطر (2026-10-12) 🔴
- **المشكلة:** في `ingest.py` المحلي، `clean()` يضغط كل المسافات والأسطر، فالفواصل `\n\n` و`\n` في `RecursiveCharacterTextSplitter` لا تعمل أبداً، والتقطيع يتم على الجمل فقط، لا على الفقرات والعناوين.
- **فكرة الحل:** إبقاء الأسطر، وضغط المسافات المتكررة فقط.

### 29. BM25 والعربي (2026-10-22) ✅
